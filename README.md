# 💼 Portfolio Pessoal

Portfolio profissional desenvolvido para apresentar meus projetos, experiências e habilidades como Desenvolvedor Full-Stack.

## 🎯 Sobre o Projeto

Este é um portfolio interativo com design moderno e animações suaves. O site apresenta um menu central com navegação fluida entre as diferentes seções, proporcionando uma experiência única ao usuário.

### ✨ Características

- 🎨 Design moderno e minimalista
- ⚡ Animações suaves e transições elegantes
- 📱 Interface responsiva
- ✍️ Efeito de digitação no nome/título
- 🎭 Cursor customizado
- 🔄 Navegação intuitiva entre seções

## 🚀 Tecnologias Utilizadas

- **[Next.js](https://nextjs.org/)** - Framework React para produção
- **[React](https://react.dev/)** - Biblioteca JavaScript para interfaces
- **[TypeScript](https://www.typescriptlang.org/)** - Superset tipado do JavaScript
- **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS utilitário
- **[shadcn/ui](https://ui.shadcn.com/)** - Componentes de UI reutilizáveis
- **[Lucide React](https://lucide.dev/)** - Biblioteca de ícones

## 📂 Estrutura do Projeto

```
├── components/
│   └── ui/              # Componentes do shadcn/ui
├── pages/
│   ├── about.tsx        # Página Sobre
│   ├── experience.tsx   # Página Experiência
│   ├── projects.tsx     # Página Projetos
│   ├── abilities.tsx    # Página Habilidades
│   └── contact.tsx      # Página Contato
├── public/
│   └── cursor.cur       # Cursor customizado
└── app/
    └── page.tsx         # Página principal
```

## 🎮 Funcionalidades

### Menu Interativo

- Menu centralizado com avatar e informações
- 5 seções navegáveis: Sobre, Experiência, Projetos, Habilidades e Contato
- Animações de transição entre as páginas

### Efeito de Digitação

- Alternância automática entre "Desenvolvedor Full-Stack" e "Pedro Gabriel"
- Animação de cursor piscante

### Redes Sociais

- Links diretos para Instagram, GitHub e LinkedIn
- Ícones com efeito hover

## 🛠️ Como Executar

### Pré-requisitos

- Node.js 18+ instalado
- npm ou yarn

### Instalação

1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/seu-portfolio.git
```

2. Entre na pasta do projeto

```bash
cd seu-portfolio
```

3. Instale as dependências

```bash
npm install
# ou
yarn install
```

4. Execute o projeto em modo de desenvolvimento

```bash
npm run dev
# ou
yarn dev
```

5. Abra [http://localhost:3000](http://localhost:3000) no navegador

## 📦 Build para Produção

```bash
npm run build
npm start
```

## 🎨 Customização

### Cores

As cores principais podem ser ajustadas no arquivo `tailwind.config.ts` ou diretamente nas classes do Tailwind.

### Cursor

Para alterar o cursor customizado, substitua o arquivo `cursor.cur` na pasta `public/`.

### Conteúdo

Cada seção do portfolio possui seu próprio componente na pasta `pages/`. Edite-os para adicionar seu conteúdo.
